# Autonomous File Editing Rule

- **แก้ไขไฟล์ได้ทันทีโดยไม่ต้องรอถาม Accept:**
  AI Agent มีสิทธิ์และหน้าที่ในการสร้าง, แก้ไข, ปรับปรุง หรือลบไฟล์โค้ดและทรัพยากรต่างๆ ที่เกี่ยวข้องกับงานได้ทันทีโดยไม่ต้องถามขอความยินยอม (Accept/Confirm) การเปลี่ยนแปลงจากผู้ใช้ ให้ดำเนินการแก้ไขและบันทึกไฟล์ให้เสร็จสมบูรณ์โดยอัตโนมัติ
