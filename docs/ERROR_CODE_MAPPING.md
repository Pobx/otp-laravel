# เอกสารรหัสข้อผิดพลาดและตารางเทียบเคียง (Error Code & Technical Mapping Dictionary)

**กฎสำคัญ:** ห้ามแสดงข้อความเชิงเทคนิคอล (Technical Exception, Database Error, SQL Query, Code Trace) ให้ผู้ใช้งานเห็นเด็ดขาด ให้แสดงเฉพาะรหัสอ้างอิง `[ERR-XXX-XXX]` และข้อความภาษาไทยที่เข้าใจง่ายตามตารางนี้เท่านั้น

## 1. หมวดความถูกต้องของข้อมูล (Validation & Data Entry: `ERR-VAL-*`)

| รหัสข้อผิดพลาด (Error Code) | สาเหตุทางเทคนิค (Technical Cause) | ข้อความที่แสดงให้ผู้ใช้เห็น (User-Facing Message) | แนวทางแก้ไขสำหรับผู้ใช้ (User Guidance) |
|---|---|---|---|
| `ERR-VAL-001` | Required field is missing / null | *"กรุณากรอกข้อมูลในช่องที่มีเครื่องหมายดอกจัน (\*) ให้ครบถ้วน"* | ตรวจสอบช่องกรอกที่มีกรอบสีแดงแล้วกรอกข้อมูลให้ครบ |
| `ERR-VAL-002` | Invalid Citizen ID (Check Digit failed) | *"เลขประจำตัวประชาชน 13 หลักไม่ถูกต้องตามหลักเกณฑ์"* | ตรวจสอบตัวเลขจากบัตรประชาชนและกรอกใหม่อีกครั้ง |
| `ERR-VAL-003` | Invalid Phone number format | *"หมายเลขโทรศัพท์ต้องเป็นตัวเลข 10 หลัก (เช่น 0812345678)"* | ตัดเครื่องหมายขีด (-) ออก และกรอกเฉพาะตัวเลข |
| `ERR-VAL-004` | Invalid Email format | *"รูปแบบอีเมลไม่ถูกต้อง (ตัวอย่าง: name@example.com)"* | ตรวจสอบการสะกดชื่อและเครื่องหมาย @ ในอีเมล |
| `ERR-VAL-005` | Invalid Buddhist Year / Date out of range | *"วันที่ระบุไม่ถูกต้อง กรุณาเลือกวันที่ตามปฏิทิน พ.ศ."* | ใช้ตัวเลือกปฏิทินที่ระบบเตรียมไว้เพื่อเลือกวันที่ |
| `ERR-VAL-006` | Number below minimum or negative | *"จำนวนที่ระบุต้องมีค่ามากกว่าศูนย์"* | กรอกตัวเลขจำนวนเต็มบวกหรือยอดเงินที่ถูกต้อง |
| `ERR-VAL-007` | Password confirmation mismatch | *"รหัสผ่านและการยืนยันรหัสผ่านไม่ตรงกัน"* | กรอกรหัสผ่านทั้งสองช่องให้ตรงกันอีกครั้ง |
| `ERR-VAL-008` | File size exceeds limit (e.g. > 10MB) | *"ไฟล์ที่เลือกมีขนาดใหญ่เกินกำหนด (ขนาดสูงสุดไม่เกิน 10 MB)"* | ย่อขนาดไฟล์หรือรูปภาพก่อนทำการอัปโหลด |
| `ERR-VAL-009` | Unsupported file extension | *"ประเภทไฟล์ไม่ถูกต้อง (รองรับเฉพาะไฟล์ .jpg, .png, .pdf เท่านั้น)"* | ตรวจสอบนามสกุลไฟล์และอัปโหลดไฟล์ที่รองรับ |

## 2. หมวดการเข้าสู่ระบบและสิทธิ์การใช้งาน (Auth & Permission: `ERR-AUTH-*`)

| รหัสข้อผิดพลาด (Error Code) | สาเหตุทางเทคนิค (Technical Cause) | ข้อความที่แสดงให้ผู้ใช้เห็น (User-Facing Message) | แนวทางแก้ไขสำหรับผู้ใช้ (User Guidance) |
|---|---|---|---|
| `ERR-AUTH-001` | Invalid credentials (Username/Password) | *"ชื่อผู้ใช้งานหรือรหัสผ่านไม่ถูกต้อง กรุณาลองใหม่อีกครั้ง"* | ตรวจสอบปุ่ม Caps Lock หรือติดต่อผู้ดูแลระบบเพื่อรีเซ็ตรหัสผ่าน |
| `ERR-AUTH-002` | Session expired / CSRF token mismatch (419) | *"ระบบหมดเวลาการเชื่อมต่อเพื่อความปลอดภัย กรุณาเข้าสู่ระบบใหม่อีกครั้ง"* | กดปุ่มเข้าสู่ระบบใหม่ ข้อมูลที่ยังไม่ได้บันทึกอาจต้องกรอกซ้ำ |
| `ERR-AUTH-003` | Unauthorized / 403 Forbidden | *"ท่านไม่มีสิทธิ์เข้าถึงหรือดำเนินการในเมนูนี้"* | หากจำเป็นต้องใช้งาน กรุณาแจ้งผู้ดูแลระบบเพื่อขอเพิ่มสิทธิ์ |
| `ERR-AUTH-004` | User account deactivated / suspended | *"บัญชีผู้ใช้งานนี้ถูกระงับการใช้งานชั่วคราว"* | กรุณาติดต่อกองการเจ้าหน้าที่หรือผู้ดูแลระบบประจำเทศบาล |
| `ERR-AUTH-005` | Organization context not selected | *"กรุณาเลือกหน่วยงาน/เทศบาลที่ต้องการปฏิบัติงานก่อนดำเนินการ"* | กลับไปหน้าเลือกเทศบาลและกดปุ่มเข้าทำงาน |

## 3. หมวดฐานข้อมูลและความซ้ำซ้อนของข้อมูล (Database & Integrity: `ERR-DATA-*`)

| รหัสข้อผิดพลาด (Error Code) | สาเหตุทางเทคนิค (Technical Cause) | ข้อความที่แสดงให้ผู้ใช้เห็น (User-Facing Message) | แนวทางแก้ไขสำหรับผู้ใช้ (User Guidance) |
|---|---|---|---|
| `ERR-DATA-001` | Duplicate entry (SQLSTATE[23000]) | *"ข้อมูลนี้มีอยู่ในระบบแล้ว ไม่สามารถบันทึกซ้ำได้"* | ตรวจสอบว่าเคยลงทะเบียนรายการนี้ไว้แล้วหรือไม่ |
| `ERR-DATA-002` | Record not found / ModelNotFound (404) | *"ไม่พบรายการข้อมูลที่ท่านต้องการ (อาจถูกลบหรือย้ายไปแล้ว)"* | กลับสู่หน้าหลักหรือค้นหาด้วยคำค้นอื่น |
| `ERR-DATA-003` | Foreign key constraint violation | *"ไม่สามารถลบรายการนี้ได้ เนื่องจากมีข้อมูลอื่นในระบบกำลังอ้างอิงอยู่"* | ต้องยกเลิกหรือลบรายการที่เกี่ยวข้องก่อนดำเนินการ |
| `ERR-DATA-004` | Insufficient inventory stock | *"ยอดพัสดุในคลังไม่เพียงพอต่อการเบิกจ่าย"* | ตรวจสอบยอดคงเหลือจริงในระบบคลังพัสดุ |
| `ERR-DATA-005` | Meter reading lower than previous month | *"เลขมาตรวัดน้ำครั้งนี้ต่ำกว่าเลขครั้งก่อน กรุณาตรวจสอบความถูกต้อง"* | ตรวจสอบตัวเลขบนหน้าปัดมิเตอร์จริงอีกครั้ง |
| `ERR-DATA-006` | Waste Bank Points balance insufficient | *"คะแนนสะสมในสมุดบัญชีธนาคารขยะไม่เพียงพอต่อการแลกรับ"* | สะสมขยะรีไซเคิลเพิ่มเติมเพื่อเพิ่มยอดคะแนน |

## 4. หมวดเครือข่ายและระบบบริการภายนอก (Network & Server: `ERR-SYS-*`)

| รหัสข้อผิดพลาด (Error Code) | สาเหตุทางเทคนิค (Technical Cause) | ข้อความที่แสดงให้ผู้ใช้เห็น (User-Facing Message) | แนวทางแก้ไขสำหรับผู้ใช้ (User Guidance) |
|---|---|---|---|
| `ERR-SYS-001` | Connection timeout / cURL error 28 | *"ระบบใช้เวลาตอบสนองนานเกินกำหนด กรุณาลองใหม่อีกครั้งในภายหลัง"* | ตรวจสอบสัญญาณอินเทอร์เน็ตแล้วลองรีเฟรชหน้าเว็บ |
| `ERR-SYS-002` | Internal Server Error (500) | *"เกิดข้อผิดพลาดในการประมวลผลของระบบ ระบบได้บันทึกรายงานเหตุการณ์ไว้แล้ว"* | กรุณาแจ้งเจ้าหน้าที่ศูนย์เทคโนโลยีสารสนเทศ พร้อมแจ้งรหัส `[ERR-SYS-002]` |
| `ERR-SYS-003` | External Payment Gateway Error | *"ระบบรับชำระเงินขัดข้องชั่วคราว ไม่สามารถทำรายการได้ในขณะนี้"* | โปรดรอสักครู่แล้วทำรายการใหม่ หรือเลือกช่องทางการชำระเงินอื่น |
| `ERR-SYS-004` | IoT Hardware Gateway Offline | *"ไม่สามารถเชื่อมต่อกับกล่องเซนเซอร์ IoT ประจำจุดหมักได้ในขณะนี้"* | ตรวจสอบแหล่งจ่ายไฟและสัญญาณอินเทอร์เน็ตของกล่อง IoT |
| `ERR-SYS-005` | SMS / Notification Gateway Failed | *"ส่งข้อความแจ้งเตือนไม่สำเร็จ แต่บันทึกข้อมูลหลักเรียบร้อยแล้ว"* | ตรวจสอบหมายเลขโทรศัพท์ของผู้รับในประวัติการติดต่อ |

## 5. กฎการเพิ่มรหัสข้อผิดพลาดใหม่ (Policy for Adding New Error Codes)

ทุกครั้งที่นักพัฒนาสร้าง Controller, Service หรือ API Endpoint ใหม่:
1. **ห้าม Throw หรือ Return ข้อความภาษาอังกฤษดิบไปยัง UI**
2. ให้นำ Error มาจัดกลุ่มเข้ากับ Prefix:
   - `ERR-VAL-*` สำหรับความผิดพลาดจากการกรอกข้อมูล
   - `ERR-AUTH-*` สำหรับสิทธิ์และการล็อกอิน
   - `ERR-DATA-*` สำหรับเงื่อนไขทางธุรกิจและข้อมูลซ้ำ
   - `ERR-SYS-*` สำหรับเซิร์ฟเวอร์และเครือข่าย
