# ADR 0003: การออกแบบระบบ UI/UX สไตล์ Senior-Friendly โทนสีขาวสบสายตาสำหรับผู้ใช้งานอายุ 40+ ปี

## Status
Accepted (วันที่ 2026-11-01)

## Context
กลุ่มผู้ใช้งานหลักของระบบ OTP 2025 คือเจ้าหน้าที่เทศบาลและประชาชนทั่วไปในท้องถิ่นที่มีอายุ 40 ปีขึ้นไป ซึ่งส่วนใหญ่สายตามีความไวต่อแสงลดลง, มองเห็นคอนทราสต์ต่ำได้ยาก, และไม่ถนัดการใช้เมาส์ขนาดเล็กหรือสมาร์ตโฟนที่มีปุ่มชิดกัน การออกแบบ UI เดิมมีสีสันที่ฉูดฉาด, ช่องข้อความมีขนาดเล็ก, และโครงสร้างหน้าจอซับซ้อนเกินไป

## Decision
กำหนด Design System และ UI Guidelines ใหม่เน้นกลุ่มผู้สูงอายุและคนทำงานท้องถิ่น:
1. **โทนสีขาว สบายตา (Pure Clean White Palette):** ใช้พื้นหลังสีขาวบริสุทธิ์ `#FFFFFF` และสีพื้นผิวเทาอ่อนสบายตา `#F8FAFC` ลดแสงสะท้อนและลดความเมื่อยล้าของสายตา
2. **ตัวอักษรและคอนทราสต์สูง (High Legibility & High Contrast):** ขนาดตัวอักษรเนื้อหาขั้นต่ำ **16px** (ฟอนต์ Sarabun / Prompt), หัวข้อ 20px–26px, และสีข้อความหลักเป็น `#0F172A` (Contrast Ratio สูงกว่า 7:1 ตามมาตรฐาน WCAG AAA)
3. **พื้นที่สัมผัสขนาดใหญ่ (Large Touch Targets):** ปุ่มกด, ช่องกรอก, และเมนูทั้งหมดต้องมีความสูงขั้นต่ำ **44px–48px**
4. **Simple Progressive Disclosure:** ลดความซับซ้อนของเมนู จัดแบ่งเป็นพอร์ทัลตามบทบาทหน้าที่ (Role-Based Portals) และลดขั้นตอนการคลิกซ้ำซ้อน

## Consequences
- **Positive:** ผู้ใช้งานอายุ 40 ปีขึ้นไปสามารถอ่านข้อความและทำรายการได้ง่ายดายโดยไม่ต้องเพ่งหรือขยายหน้าจอ ลดความผิดพลาดในการคลิกปุ่มผิด
- **Negative:** หน้าจอต้องใช้พื้นที่แนวตั้ง (Vertical Real Estate) มากขึ้น ทำให้แต่ละหน้ามีความยาวเพิ่มขึ้นเล็กน้อย
- **Constraints (สำหรับ AI Agent):**
  - ห้ามใช้ตัวอักษรเนื้อหาขนาดเล็กกว่า 15px–16px ในส่วนที่ต้องอ่านข้อมูลสำคัญ
  - ห้ามใช้ปุ่มกดหรือ Input ที่มีความสูงต่ำกว่า 44px–48px เด็ดขาด
  - ต้องรักษาคอนทราสต์ของสีตัวอักษรกับพื้นหลังให้อยู่ในเกณฑ์ WCAG AA เป็นอย่างต่ำ
